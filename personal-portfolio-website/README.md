# Personal Portfolio Website

## Project Description
A Next.js-based portfolio site showcasing projects and research with animated transitions and a markdown-powered blog. The project addresses the need for a polished online presence and explores modern React features like static generation.

## Technologies and Tools Used
- Next.js
- TailwindCSS
- Framer Motion
- EmailJS

## Setup & Installation
1. **Prerequisites**
   - Node.js
2. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd personal-portfolio-website
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Run the development server**
   ```bash
   npm start
   ```
   Visit `http://localhost:3000` to view the portfolio.
5. **Build for production**
   ```bash
   npm run build
   ```
6. **Deployment**
   Deploy to Vercel or similar platform. Ensure environment variables for EmailJS are configured.

## Core Features
- Responsive layout with dark/light mode
- Animated project cards using Framer Motion
- Markdown-powered blog with static generation
- Contact form using EmailJS
