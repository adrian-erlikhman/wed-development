# Personal Portfolio: Research Report

## Abstract
This report examines the design of an interactive developer portfolio emphasizing performance, accessibility, and visual storytelling through animation.

## Introduction
An effective portfolio communicates expertise and personality. We analyze a Next.js implementation that balances dynamic effects with strong core web vitals.

## System Architecture
The site uses Next.js for static generation, TailwindCSS for styling, and Framer Motion for animation. Content is fetched from Markdown files to facilitate blogging and project documentation.

## Implementation
We optimized images and employed lazy loading to keep the bundle small. Dark and light themes adapt via CSS variables, while Framer Motion orchestrates page transitions.

## Results
Lighthouse audits of the prototype scored 95+ across performance and accessibility metrics. User tests indicated smooth navigation and positive perception of animations.

## Future Work
Planned research includes integrating Open Graph image generation, WebGL project showcases, and automatic deployment pipelines for continuous updates.
