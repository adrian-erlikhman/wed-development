# Web Development Projects

This repository showcases a set of advanced web applications built with various modern technologies. Each project resides in its own folder with a small backend server and frontend demo. Detailed setup, development, and deployment instructions are in the README of each project, and a companion `RESEARCH.md` discusses the project's design and findings.

## Available Projects

- **safejew-community-web-platform** – tracks and reports antisemitic incidents on an interactive map.
- **personal-portfolio-website** – personal site showcasing projects and research with animations.
- **findash-financial-dashboard** – displays real-time financial data and portfolio analytics.
- **smartspend-personal-finance-manager** – tracks budgets, expenses, and goals.
- **startup-funding-simulator** – models how equity and valuation change through funding rounds.
- **ai-resume-builder** – generates resumes with the help of AI and exports them as PDFs.
- **collabnotes-real-time-markdown-editor** – collaborative notes with markdown support.
- **designify-community-driven-merch-creator** – lets communities vote on merch designs and purchase popular items.

Clone any project directory and run `npm install` followed by `npm start` to launch the sample locally.
